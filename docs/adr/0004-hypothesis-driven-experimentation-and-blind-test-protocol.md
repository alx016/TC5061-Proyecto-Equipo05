# Experimentación Dirigida por Hipótesis y Protocolo Blind Test Out-of-Time

Para asegurar rigor científico y prevenir fuga de información temporal en la optimización de hiperparámetros de P1, P2 y P3, se decide implementar el patrón Study/Trial mediante Nested Runs en MLflow Tracking. Las corridas padre formalizan la hipótesis y el objetivo primario de optimización, mientras que los ensayos (trials) hijos se entrenan en datos de enero a septiembre de 2024 y se seleccionan exclusivamente sobre el periodo de validación (octubre a noviembre). El conjunto de prueba de diciembre de 2024 queda reservado como un Blind Test Gate de una sola ejecución reservada para el modelo seleccionado como candidato a producción, evaluando balance de Pareto entre métrica de negocio, latencia y complejidad.
